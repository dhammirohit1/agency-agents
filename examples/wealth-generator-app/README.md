# Aurelius | Autonomous Wealth Generator Dashboard

This directory contains a prototype frontend for the **Aurelius** agent's monitoring dashboard.

## 🚀 Overview
The dashboard is designed to provide 24/7 visibility into the agent's autonomous operations, including:
- **Real-time Profit Tracking**: Visualizing the 60/40 split in action.
- **Revenue Channel Monitoring**: Status of trading bots, e-commerce stores, and affiliate links.
- **Sub-Agent Orchestration**: Tracking the tasks assigned to specialized agents (Researchers, Growth Hackers, etc.).
- **Security Protocols**: Access to the "Drain Wallet" emergency protocol.

## 🛠️ Deployment
This is a static frontend prototype built with HTML5 and Tailwind CSS.
To "deploy" or view the dashboard:
1. Open `index.html` in any modern web browser.
2. The dashboard includes a simulation script that updates metrics in real-time to demonstrate the agent's 24/7 activity.

## 🤖 Integration
In a production environment, this frontend would be connected to the **Aurelius** agent's backend via an API or MCP (Model Context Protocol) server to display live data from the agent's wallets and orchestration logs.
