# 🚀 Aurelius Quickstart Guide

This guide will walk you through deploying and using the **Autonomous Wealth Generator (Aurelius)** system.

## 🛠️ Step 1: Install the Agent Persona

The "brain" of the system is the agent persona. You need to install it into your preferred AI tool.

### For Claude Code
```bash
# In the root of the agency-agents repository
./scripts/install.sh --tool claude-code
```

### For Cursor
```bash
# In the root of the agency-agents repository
./scripts/install.sh --tool cursor
```

## 🌐 Step 2: Deploy the Dashboard

The dashboard provides 24/7 visibility into your revenue streams.

### Option A: Local View (Fastest)
Simply open `examples/wealth-generator-app/index.html` in your browser.

### Option B: Static Hosting (Vercel/Netlify)
1. Push this repository to GitHub.
2. Connect your GitHub to Vercel or Netlify.
3. Set the "Root Directory" to `examples/wealth-generator-app/`.
4. Deploy.

## 💰 Step 3: Fund & Initiate Aurelius

Launch your AI tool (Claude Code or Cursor) and use the following "Genesis Prompt" to start the engine:

> "Activate the **Autonomous Wealth Generator** agent. I am funding the engine with my initial **$10 seed**.
>
> 1. Execute **Phase 1: The Cold Start**.
> 2. Spawn a **Product Trend Researcher** to find a high-intent digital niche.
> 3. Verify my linked bank/crypto account for the **40% daily payout**.
> 4. Report status every 24 hours."

## 🔒 Step 4: Security Configuration

To ensure your funds are safe:
1. Provide your **Special Key** (a long, unique string) to the agent when prompted.
2. Link your **Binance/Alpaca/Stripe** API keys via your tool's secure environment variable storage.
3. The agent is hardcoded to never touch your 40% payout—it is automatically moved to your primary account.

## 📈 Monitoring Progress

- **Dashboard**: Watch your "Total Assets" grow from $10.
- **Orchestration**: See which sub-agents (Growth Hacker, Content Creator) are currently active.
- **Daily Splits**: Check your bank/wallet daily at 04:00 UTC for your 40% profit share.

*Note: This is an AI-orchestrated financial system. Start with only what you can afford to lose ($10) and scale as the agent proves profitability in your chosen niches.*
